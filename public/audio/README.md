# 🎶 Audio Folder: `public/audio/`

Welcome! This is where you can place the Tamil birthday song.

## How to add your Tamil song:

1. Copy your song into this folder and name it:
   `birthday-song.mp3`

2. That's it! The website will automatically detect and play your Tamil song seamlessly.

3. (Optional) In `src/config/birthdayConfig.ts`, you can update:
   - `title`: e.g. "Kannana Kanne" or "Azhagiya Tamil Magal"
   - `artist`: e.g. "Anirudh / Sid Sriram"
   - `promptLabel`: "A little melody for your special day 🎶"

Note: If no audio file is provided yet, our website plays a dreamy, gentle ambient birthday chime melody synthesized directly through the browser Web Audio API, so there are never any broken links or silence!
